## 사례 ↔ 원인 매핑

스크린샷의 “주인님” 망각은 다음 원인의 *동시 작용*이다.

1. F1·F2(아키텍처): T1 부재로 critical 인사이트가 자동 주입 자리에 없음.
2. F3·F4(retriever): 새 세션이라 L0/L1/L1.5/L2 모두 0.
3. F5(search): L4 키워드가 “뭐하고 있었어” ↔ 영어 인사이트 본문에서 0매치.
4. F8(config): L3 벡터가 키 누락 또는 threshold 미달로 0.
5. F9(persona): 에이전트가 능동 검색할 동기 없음.
6. 결과: chunks 0 → memory_context 빈 문자열 → MemoryContextBlock “” → system prompt에 메모리 섹션 자체가 없음.

각 단계에 fix가 들어가야 본 사례가 재발하지 않는다. 단, **F1만 고쳐도 본 사례 자체는 재발하지 않는다**(인사이트가 항상 주입되므로). 따라서 우선순위는 명확하다.
