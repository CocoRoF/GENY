## 환경 변수 / 설정

| 키 | 효과 | 기본 |
|---|---|---|
| `MEMORY_PROVIDER` | `disabled` / `ephemeral` / `file` / `sql` | `disabled`(Geny), `ephemeral`(executor-web) |
| `MEMORY_ROOT` | file provider 루트 | (없음) |
| `MEMORY_DSN` | sql provider DSN | (없음) |
| `MEMORY_PROVIDER_ATTACH` | 새 provider를 Stage 2/18에 부착할지 | `false` |
| `MEMORY_API_PROVIDER` | controller가 provider-first로 라우팅할지(Phase 7) | `false` |
| `MEMORY_LEGACY_STM/LTM/NOTES/VECTOR/CURATED` | 레이어별 legacy 경로 사용 여부 | 모두 `true` |
| settings.json `memory.tuning.slim_mode` | retriever를 vault_map 모드로 | (없음 → False) |
| settings.json `memory.tuning.recent_turns` | L0 길이 | 6 |
| settings.json `memory.tuning.enable_vector_search` | L3 활성화 | True |
| settings.json `memory.tuning.max_inject_chars` | 총 char budget | vtuber 8000 / worker 10000 |
| `LTM_EMBEDDING_API_KEY` | 임베딩 키(`vector_memory.py`) | (없음 → vector 비활성) |

## 시스템 프롬프트가 받는 것

```
[PersonaBlock]                 ← 정적 텍스트
[DateTimeBlock]                ← 현재 시각
[MemoryContextBlock]           ← Stage 02 retriever 결과(없으면 빈 문자열)
[ToolInstructionsBlock]        ← 옵션
```

이 4개가 시스템 프롬프트의 표준 꼬리(tail blocks). “주요한 사실” 자리는 어디에도 없다.
